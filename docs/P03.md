# P03 : INVESTIGATION PHASE

The first phase that actually calls an LLM. After P2 has narrowed the incident to a shortlist of suspect services (branch_ids), P3 spins up a bounded investigator per candidate, gives each one a small fixed-size evidence bundle, and asks it two questions: "is this service abnormal, and why?" and then, across the branch, "what's the local root cause?"

## What it does

The entry point is `investigate_investigation()` at `p3_investigate.py:452`. It validates that the ranking matches the admitted scope (ranking.scope_ref == scope.scope_ref), then forms the branch set as P2's branch_ids intersected with the scope's services.
Before spending anything, it reserves hypothesis slots fairly: 20% of the 30-hypothesis budget is held back for expansions, the rest is round-robined across branches so a slow or verbose branch can't starve the others.
Each branch then runs in two passes, it exists so a slow branch can never deadlock its parents:

1. Pass A (`_run_branch_calls::p3_investigate.py`): fetch the bundle, run self-verify (a cheap-tier call returning a typed NodeVerdict), then run hypothesis batching (default tier) to produce 0..N proposals. Each proposal is strictly validated , the candidate must be the branch itself, every evidence_refs id must be in the bundle, and any structured claim must match a precomputed bounded option (_metric_claim_options for exact-column excursions, dependency_claim_options for same-trace span pairs). Bad proposals are rejected individually with a recorded reason rather than failing the branch.
2. Pass B (`_consolidate::p3_investigate.py`): leaf-to-root consolidation over the verdicts pass A produced. Children are the branch's callees inside the branch set; the payload is frozen typed verdicts only, never a transcript.

Scoring follows : sc is a zero-token signature self-consistency score over each hypothesis's cited modalities, with a floor , no graph read means sc = 0; then R = α·r + (1−α)·sc.
Expansion happens once, outward only: branches whose confidence is below θ=0.6 and that didn't error get their non-branch callees explored in seeded random batches of 2, capped at 6 per branch.
