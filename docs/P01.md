# P1 : Scope Phase
P1 turns the single anchor service from P0 into a small, bounded, read-only evidence picture

P2 ranking, the P3 agent bundles, the agent tools and P6 all read from this snapshot. They are not meant to read the graph directly.

1. **Copies the graph first.** It makes a private `GRAPH.COPY` of the session graph and reads from that copy.
2. **Picks services.** It takes the anchor plus its one-hop `DEPENDS_ON` neighbors in both directions. Only edges with `invariant = true` count. The cap is 40 nodes.
3. **Fetches evidence.** It pulls alerts, logs, metric anomalies, spans and traces within the ±15 minute window, plus recent deployments and config changes.
   - **Fair fetching:** this is done per service, per modality, and separately before and after onset. Sampling is onset-local, so one noisy service can't use up the budget.
   - **Series cap:** metric series are capped at 12.
4. **Computes per-service statistics** (`service_statistics`):
   - severity vector `sev_m`, `sev_l`, `sev_tc`: the maximum |z| per modality, and 0 if the modality is absent
   - span self-time: parent duration minus the union of direct-child intervals, flagged above 500 ms
   - n-σ evidence: metrics with |z| > 3 within ±60 s of onset
   - deploy proximity: `exp(−Δhours/24)` since the last change
5. **Records gaps.** It writes `EvidenceGap` nodes for `no_traces` and `no_logs`, and for `scope_truncation` when anything was cut. `unscored_metrics/logs/traces` (present_unscored), so a 0 in the severity vector means "not measured," not "looked normal."
6. **Writes and publishes.** It writes the stats back onto the session graph's `Service` nodes and publishes an immutable `ScopeResult`. The `ScopeResult` carries a fingerprint and a config echo.
